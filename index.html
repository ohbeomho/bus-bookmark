자동 새로고침

앱 화면이 보일 때만 새로고침해요. 모든 사용자가 하루 호출 한도를 함께 쓰므로 간격을 길게 할수록 좋아요.

즐겨찾기 그룹

출근·퇴근처럼 묶어 두면, 같은 그룹에서 지금 가장 빨리 탈 수 있는 노선을 홈 화면에 크게 보여 줘요. 노선마다 그룹은 홈 화면이나 지도 정류장 화면에서 고를 수 있어요.

    출근 무지각 체크인

    목표 시간을 정하면 홈 화면에 탑승 완료 버튼이 생겨요. 목표 시간까지 탑승하면 무지각, 넘으면 지각으로 그날 하루치만 기록돼요. 기록은 이 기기에만 저장되고 아무 데도 보내지 않아요.

    앱 설치

    이 서비스는 PWA(설치형 웹앱)예요. 홈 화면에 설치하면 주소창 없이 앱처럼 바로 열리고, 인터넷이 끊겨도 즐겨찾기 목록은 열려요. 앱 스토어를 거치지 않고 용량도 거의 차지하지 않아요.

    ✓ 지금 설치된 앱으로 실행 중이에요.

    버튼을 누르면 바로 설치돼요.

    아래쪽 공유 버튼(□↑)을 누르고 '홈 화면에 추가'를 선택하세요.

    공유 버튼(□↑)을 누르고 '홈 화면에 추가'를 선택하세요. 메뉴에 없으면 Safari에서 이 주소를 열어 주세요.

    오른쪽 위 메뉴(⋮)에서 '앱 설치' 또는 '홈 화면에 추가'를 선택하세요.

    아래쪽 메뉴(≡)에서 '현재 페이지 추가' → '홈 화면'을 선택하세요.

    주소창 오른쪽의 설치 아이콘을 누르거나, 브라우저 메뉴에서 '설치' 항목을 선택하세요.

    메뉴 막대의 파일 → 'Dock에 추가'를 선택하세요.

    이 브라우저는 앱 설치를 지원하지 않을 수 있어요. Chrome·Edge·Safari에서 열면 설치할 수 있어요.

    기기별 설치 방법
    • iPhone·iPad (Safari): 공유 버튼(□↑) → '홈 화면에 추가'
    • iPhone·iPad (Chrome 등): 공유 버튼(□↑) → '홈 화면에 추가' (없으면 Safari에서 열기)
    • Android (Chrome): 메뉴(⋮) → '앱 설치' 또는 '홈 화면에 추가'
    • Android (삼성 인터넷): 메뉴(≡) → '현재 페이지 추가' → '홈 화면'
    • PC (Chrome·Edge): 주소창 오른쪽 설치 아이콘, 또는 메뉴 → '설치'
    • Mac (Safari): 메뉴 막대의 파일 → 'Dock에 추가'

    개인정보

    위치 정보는 이 기기 안에서만 쓰며 어디에도 보내거나 저장하지 않아요. 도착 정보를 받을 때는 도시코드와 정류장 ID만 중계 서버로 전달되고, 중계 서버는 아무것도 저장하지 않아요. 즐겨찾기는 이 기기의 브라우저에만 저장돼요.
